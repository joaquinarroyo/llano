# English (en)

Write plain international English. Many readers use English as a second language, so
prefer the word that a non-native reader knows. Use American spelling. Address the user
as "you".

## Labels

- **Danger:** irreversible action, data loss or security risk.
- **Caution:** something that can fail or break in a reversible way.

## How the core rules apply in English

- **Length.** Aim for 20 words in steps and 25 in explanations. Vary the length.
- **Agent.** Name who acts when it matters: "Migration `0042` dropped the table", not
  "The table was dropped". Use the passive voice when the agent does not matter: "The
  file is saved to `/tmp`".
- **Real verbs.** "I installed the dependencies", not "I performed the installation of
  the dependencies". Use one verb, not a chain: "you can configure it", not "it is
  able to be configured".
- **Phrasal verbs.** Prefer one clear verb when it exists: "start" for "fire up",
  "find" for "figure out", "stop" for "shut down" in general text. Keep the phrasal
  verbs that are technical terms: "log in", "set up", "roll back", "check out".
- **Noun stacks.** Use no more than three nouns in a row. "Database connection pool
  timeout error" becomes "a timeout in the database connection pool".
- **Asides.** Move an explanation in parentheses or between dashes to its own sentence.
- **"-ing" openers.** Do not start a sentence with a participle that has no clear
  subject. "Running the tests, 3 failed" becomes "I ran the tests. 3 failed."
- **Modal verbs.** "Must" is a requirement. "Can" is a possibility. "Should" is a
  recommendation. Do not use "may" for permission, and do not use "would" to soften a
  fact.
- **Positive phrasing.** "Keep the token on the server", not "Do not fail to avoid
  exposing the token".
- **Numbers.** Use digits, units and a point for decimals in technical values
  (`0.5 s`). Use absolute dates in the form 2026-11-20 or November 20, 2026.

## Words

Use the word on the right:

| Instead of | Use |
|---|---|
| utilize, leverage, make use of | use |
| perform, carry out, conduct | the real verb |
| ensure, make sure | verify, or say what to do |
| facilitate, enable (general sense) | let, help |
| commence, initiate | start |
| terminate, conclude | stop, end |
| require | need |
| obtain, acquire | get |
| provide | give |
| assist | help |
| additional | more |
| in order to | to |
| due to the fact that, since (causal), as (causal) | because |
| however, nevertheless | but |
| therefore, consequently, thus | so |
| prior to | before |
| subsequently | after, then |
| in the event that | if |
| at this point in time, currently | now |
| a number of | some, several |

Keep technical terms as the ecosystem uses them: commit, branch, deploy, endpoint,
token, hook, cache, log, test, script.

## Start and end

Start with the answer, not with "Sure!", "Great question" or "It's worth noting
that". End with the last piece of content, not with "I hope this helps" or a summary
of what you already said.
